# 多 bot 协作与调度（运维 bot 为核心）

本文记录一套在 Grok Bot 上长期运行的多 bot 分工方式。所有名字、主机、域名都是占位符，照着替换成你自己的即可。

## 1. 角色总览

| 角色 | 职责 | 不做什么 |
| --- | --- | --- |
| **Steward（总调度）** | 接用户的话，判断该交给谁，用 bot 间消息派活，汇总结果回给用户 | 不亲自做长任务 |
| **运维（Ops）** | 维护看板和本仓库、巡检、额度刷新、提醒转发、备份、监控、接入新 bot | 不做业务开发 |
| **审核官（Reviewer）** | 多模型交叉审核方案、ADR、PR、实验 | 只审不改、不跑任何东西 |
| 系统架构师 | 架构方案、ADR、RAG/Agent 设计 | |
| 开发工程师 | 写代码、开 PR、写管道 | |
| 科研助理 | 论文、实验 | |
| 数据工程师 | 数据摸底、清洗、建模、数据字典、SOP | 动原始数据前先问用户，始终保留原始副本 |
| 邮箱助理 | 所有邮件相关的任务 | 不直接发信，只出草稿 |

专职 bot 可以按需增减。判断标准：一类工作要持续几周以上、需要长期记住现状和规则，就值得单独建一个 bot；零散的活交给现有 bot。

## 2. 运维 bot（核心）

**为什么要单独的运维 bot**：看板、脚本、仓库、备份这些「基础设施」如果由 Steward 顺手维护，会和日常派活抢上下文，出了问题也没人负责。把它们交给一个专职运维 bot，Steward 只需要说一句「让运维处理」。

运维 bot 的固定职责：

1. **维护看板和本仓库**：改 `st`/`stwatch`/`stnudge`、部署页面、更新文档；对外仓库的每次提交都先脱敏扫描（`.privacy-terms` + `scripts/scan-history.sh` + `tests/test_privacy.py`）。
2. **额度刷新**：例行任务每 30 分钟跑一次 `refresh-quotas.sh`（只读各家 `/usage` 面板，不发模型请求、不耗额度），把 Claude Code / Gemini / Kimi 等的剩余额度推到看板。
3. **看板巡检**：定时检查任务卡片是否和真实进度一致，清理过期或重复的卡片，一次性例行任务跑完立刻 `st done`。
4. **停滞任务提醒**：任务 45 分钟没有动静，或已经超过 ETA，就给对应 bot 发**优先**消息唤醒；连续两次提醒没有回应，告诉用户。
5. **提醒转发**：读 `stnudge queue list`，用 bot 间消息转给对应 bot，再 `stnudge queue ack`。
6. **备份**：每天备份共享电脑的工作目录到云盘，密钥只放在一台指定的私有机器上，不进云盘、不进仓库。
7. **接入新 bot**：新 bot 建好后，Steward 通知运维把它加到看板、纳入巡检和提醒。
8. **服务器 / 共享电脑监控**：维护每台机器的上报 cron（见 [cloudflare.zh-CN.md](cloudflare.zh-CN.md)），超过 15 分钟没上报标黄，30 分钟标离线。

运维 bot 的边界：生产环境、别人的个人数据目录、用户明确说「不要动」的东西一律不碰；删除、对外发布、改仓库可见性都先问用户。

## 3. 审核官：多模型交叉审核的中心

- 架构师、开发、科研助理、数据工程师**主动**把方案、ADR、代码/PR、实验和论文改动发给审核官。
- 审核官只审，不改文件、不跑代码，输出问题清单和结论（通过 / 需修改 / 阻断）。
- 默认两位审核模型（例如 Claude + Gemini）。给 Claude Code 的提示词一律用英文。
- **按额度回退**：某家额度紧张（例如周额度只剩 10% 以下）时，按看板上的额度读数把审核改派给其他模型（如 Gemini、Kimi），额度恢复后再切回。
- 审核前后都要跑一次对应的额度脚本，保证看板读数是新的。

## 4. 通用规则

- **长任务一律用 `stwatch`** 托管（自带心跳、卡死检测），不要裸跑后台进程。
- **每个 bot 都用 `st` 汇报**：开始、阶段变化、ETA 变化、完成都要写；每个例行任务也登记一张 `--state routine` 卡片。
- **bot 间优先消息**：紧急唤醒（停滞提醒、阻断问题）用优先级消息；普通汇报用普通消息。
- **邮件统一走邮箱助理**：任何发信都先出草稿，由用户本人确认后发送。
- **密钥**：只放在指定的私有位置；不打印、不进仓库、不交给不该拿的代理（例如不把云服务凭据交给编码代理）。
- **只用免费额度**的云服务。
- 时间统一按用户所在时区汇报。
